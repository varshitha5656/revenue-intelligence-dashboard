# Revenue Intelligence Dashboard

## Overview
An interactive dashboard built to analyze sales data and extract meaningful business insights such as revenue trends, profit analysis, and regional performance.

---

## Key Features
- Interactive dashboard using Streamlit
- Monthly revenue trend visualization
- Category-wise and region-wise analysis
- Profit and profit margin calculation
- KPI metrics for total sales and orders
- Dynamic filters for category and region
- Clean data handling and preprocessing

---

## Tech Stack
- Python
- Pandas
- Streamlit
- Excel (for initial data handling)

---

## Data Processing
- Converted date fields for time-based analysis
- Created new columns: Profit and Profit Margin
- Aggregated monthly revenue data
- Cleaned and validated dataset before visualization

---

## Insights
- Identified revenue trends over time
- Highlighted underperforming categories and regions
- Compared sales vs profit for better decision-making

---

## Deployment
Deployed using Streamlit Community Cloud
